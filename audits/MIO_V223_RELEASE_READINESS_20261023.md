作成：2026-10-23 / 開発ブランチ `feature/mio-ip-five-history-20261021`
公開サイト・GAS・スプレッドシート・Vercel環境設定には**変更なし**。

## 変更の目的
この開発ブランチには、パスキー認証、Web ID最大5件、短期IPハッシュ観測、GAS用の読み取り専用照合があるが、個別テストに成功しただけでは本番公開の安全性を証明できない。とくに実GAS公開版・編集コード・トリガーとの同一性が未確認。

## 今回追加
- `mio-release-readiness-v223.js`：14個の独立した公開前チェックの集約。いずれか一つでも未証明であれば `canRelease:false`。完全一致の `true` 以外は認めない。
- `mio-release-check-v223.mjs`：開発用CLI。`--audit` は現在の不足項目を出力して終了コード0、`--release` は未確認がある現状では終了コード1として停止。**実際の公開操作・デプロイは実行しない**。
- `tests/mio-release-readiness-v223.test.mjs`：判定関数10件。すべての条件が揃った場合のみ承認、個別1項目だけ欠けても拒否すること、型に弱い値や改ざんを拒否。
- `tests/mio-release-check-cli-v223.test.mjs`：CLIに関する5件。現状の公開拒否、未知の引数拒否、環境変数からの偽装防止を試験。
- GitHub Actionsで上記テストと `--audit` モードを自動実行。

## 現時点で公開不可の主な理由
1. **GAS実本番の4ファイル・v12デプロイ・編集トリガー未取得。** Google Driveからシートは読めるが、Apps ScriptプロジェクトはAPI未対応/取得不可。
2. 本番の専用 `identity_attestation` アクション未配備。現行の `status` アクションには状態補完を伴う可能性があり、パスキーの本人照会へ使用しない。
3. ブラウザ停止・Cookie失効のGAS同期、初回本人確認の真正な証明、実iPhone/Androidパスキー、復旧・バックアップ・既存皆勤ガチャ等の公開前検証は未完了。
4. 23行目の復旧先MIO-ID不一致・別名、40行目の不完全な記録は管理者確認待ち。24行目は名前の前後空白のみで台帳整合する修正候補を確認済みだが、**まだ本番未反映**。

## 解釈上の注意
- このチェックは**開発ブランチの読み取り専用判定ツール**であり、現時点の実際の本番デプロイ権限やGitHubブランチ保護を技術的にロックしたものではない。
- `--release` の引数は名前だけで、デプロイ実行は含まれない。これを本番配備工程に組み込むには、別途独立したレビューが必要。
- チェックの `true` はコード上の値なので、エビデンス（本番ソースハッシュ、トリガー一覧、実機テスト記録、本人確認記録等）を**別途正規の方法で確認**しなければならない。
- 自動テストの成功件数は、単体・モックGAS・一時DB・ソフトウェア認証器の合計。**本番で稼働可能という意味ではない**。
