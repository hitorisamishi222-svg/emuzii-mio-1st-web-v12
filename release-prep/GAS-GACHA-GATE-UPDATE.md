# Apps Script更新手順（全置換・スマホ用）

対象プロジェクト: 既存の「emuzii 翠央1周年 Web連携 v1.2」  
対象ファイル: `GachaAdminV188.gs`  
全置換用コード: [GachaAdminV188-FULL-REPLACE.gs](./GachaAdminV188-FULL-REPLACE.gs)

## 操作

1. Apps Scriptを開き、左のファイル一覧から **GachaAdminV188.gs** をタップ。
2. [全置換用コード](./GachaAdminV188-FULL-REPLACE.gs)を開いて、コード全体をコピー。
3. Apps Scriptに戻り、**GachaAdminV188.gsの中だけ**を全選択して、コピーしたコードに置き換える。ほかのファイルは変更しない。
4. 保存する。
5. 上部の関数選択欄から **setupGachaGateOnlyV188_** を選び、実行を1回押す。初回のGoogle承認が表示されたら承認する。
6. 管理画面シートの一番下に「メンシプガチャ受付」「ラキフェス受付」が追加され、どちらも未チェック（OFF）なのを確認する。

**setup() は実行しないでください。**  
全置換用コードは既存の付与処理関数を含みます。管理画面シートの既存セルや参加者データを作り直すことはありません。コードファイルだけを置き換えます。

## 既存ウェブアプリの更新と確認

1. Apps Scriptの「デプロイ」→「デプロイを管理」を開く。
2. 現在使っているウェブアプリの編集アイコンを選び、新しいバージョンで更新する。**新しいデプロイは作らず、既存の `/exec` URLを維持する。**
3. 受付スイッチ2つがOFFのまま、ガチャ一覧が停止し、抽選が成立しないことを確認する。
4. チェックイン等、ガチャ以外の既存機能も確認する。
