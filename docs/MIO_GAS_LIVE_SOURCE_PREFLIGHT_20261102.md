# 既存GAS稼働ソースの非公開バックアップ照合（2026-11-02）

**目的：** 翠央1周年の既存 Apps Script を壊さず、Web管理19関数と`doPost`の現物を判定する。**本番GASへ書き込むツールではない。** GitHubの`main`や保存された`.gs`ファイルと、現在のApps Scriptエディタにあるコードが同一とは限らない。

## 手順（運営の許可・実際の管理画面から取得する場合のみ）

1. 既存管理シートから「拡張機能 → Apps Script」を開き、**既存プロジェクト名・デプロイID・現行デプロイ版**を管理者が確認。秘密鍵・スクリプトプロパティ・参加者データは第三者へ送らない。
2. 稼働スクリプトの**すべての `.gs` ファイル**を、手元の非公開フォルダへそれぞれ保存する。アプリのデプロイを変更・追加しない。バックアップ原本には編集をしない。対象ファイルが不明・取得できない場合はここでSTOP。
3. Node.jsの使えるPC上で、このリポジトリの開発ブランチを用意し、読み取り専用CLIを実行する。ファイル名は例。**実行時の引数には本当に保存した全`.gs`ファイルを渡す**。

```bash
node scripts/mio-gas-source-preflight.mjs "/private/backup/Code.gs" "/private/backup/Other.gs"
```

このスクリプトは、ソースを解析して**関数数・重複数・`doPost`数・BRIDGE_SECRET確認が管理ルートより前か・ScriptLockの取得と失敗時returnが管理処理より前か**を表示する。秘密鍵・コード全文・参加者情報の値はログに出さない。読み取り以外のファイル操作、Spreadsheet/GAS/DBへの接続はしない。CLIは安全が確定しない限り**終了コード0を返さない**。

| 判定 | 意味 | 次の対応 |
|---|---|---|
| `NO_OPS_CANDIDATE_ONLY` | 管理19関数なし・`doPost`が1つ。保存済み旧版に相当する構造 | 既存バックアップと現行デプロイ版を照合。認証・ロック内でのルート差分を設計。**自動追加禁止** |
| `ALL_OPS_IN_SOURCE_UNVERIFIED_DEPLOYMENT` | 管理19関数が1回ずつあり、管理ルート順序の静的条件を満たす | **すでに管理処理がある可能性**。追加ファイル不要か確認。現行デプロイと一致するか別途実機確認 |
| `BLOCKED_REVIEW` | 関数の重複、部分追加、`doPost`重複、認証順序/ロック異常など | **変更・デプロイ停止**。現物コードを非公開で修正レビューしてから再判定 |

**重要：** この検査はソース文字列の保守的な静的確認で、認証やロックの実行経路を保証するものではない。危険な順序・失敗時return欠落は停止判定にするが、判定が良好でも管理者によるコードレビュー、現行デプロイ照合、バックアップ、読み取り専用の実機確認が別途必要。

## 既存管理シートで確認済みの安全停止条件

- `emuzii_Web登録`のログインIDは**21列目**、`emuzii_ガチャ`は**17列**の想定と一致。
- **`emuzii_ガチャ付与履歴`のJ列には`Web操作ID`見出しがない。**
- **`emuzii_Web管理操作履歴`のタブが現行のシート一覧にはない。**
- これらのタブ/列を作成する動作は**データのスキーマ変更**なので、必要性とバックアップ、付与/景品/当選履歴の整合、運営の明示承認が揃うまで一切行わない。
- `MIO_GACHA_ADMIN_OPS_RELEASE`はOFF。書き込み操作・管理承認・回数付与を実施しない。
- 結果が`ALL_OPS_IN_SOURCE_UNVERIFIED_DEPLOYMENT`でも、それだけで本番のGAS実コード・デプロイ版の一致は確認できない。
- `mioAdminOpsRead_`の候補コードにSheet書き込みがないことは静的確認済みだが、実稼働版の確認は未実施。**接続確認は段階的・読み取り専用が先。**

## 2026-11-02：スマホだけでも使える端末内検査画面（開発版のみ）

- `/mio-gas-local-check.html` に、ブラウザだけで現行GASソースの構造を確認できるプライベート検査画面を追加。既存 `gacha-web-gate.html` の停止中管理パネルから開ける。
- 既存スプレッドシートの「拡張機能 → Apps Script」で確認した**現行の全ファイル**を、手元の `.gs` / `.txt` として選択。ファイル内容の読取・関数抽出・判定は端末内だけで行う。取得・バックアップそのものは自動実行できず、稼働プロジェクトを変更しない。
- 19管理関数の存在/欠落、一般関数の重複、`doPost` の宣言数、管理ディスパッチの権限確認・ScriptLockの順番を**保守的な文字列検査**で判定する。全量を選ばないと判定は不完全。文字列検査は実行経路の保証ではない。
- 秘密鍵、ソース本文、ファイル名は結果に含めず、ファイル本文をサーバーへアップロードしない。保存可能なJSONは件数と固定された停止理由コードのみ。ファイル形式 `.gs/.txt`、最大30ファイル・合計8MB。

## 2026-11-02：誤判定防止と、復元用バックアップの端末内照合を追加

- Node CLIとスマホWeb検査の両方に、コメントおよび引用文字列を関数の定義・管理者認証/ロック実行の検査から除外する保守的な走査処理を導入。「コメントアウトされたdoPost」や「文字列で書かれたsecret確認」を本物の安全処理として誤認しない。構文解析器・実行経路の証明ではなく、現行GASのソースレビューは引き続き必須。
- 端末内ページ `/mio-gas-local-check.html` に「元ファイル一式」と「復元用バックアップ一式」を選んで**同じ名前・同じバイト内容かSHA-256で比較**する機能を追加。2組の選択は手動。最大各30ファイル、各8MB。ファイル名・コード・ダイジェスト・秘密鍵は画面、ネットワーク、診断JSONへ送信・保存しない。一致・不一致だけ表示する。
- ファイル内容の照合に成功しても、**それが運用Apps Scriptの稼働デプロイ版であるという証拠にはならない**。製品側の承認・回数付与、本番URL、既存GAS、Googleシート、DBは一切変更しない。
- Web上のGASソース読取中「結果を消す」を押しても、古い非同期読取の結果を後から復活させない制御は維持。バックアップ照合にも同じ世代番号方式を使う。
- Node/Browserの判定一致と偽コードの不合格は `tests/mio-gas-local-browser-parity.test.mjs`。バックアップの同一・相違・秘密ソースの表示なしを実Chromeで確認するのは `tests/mio-staging-mobile-chromium.mjs`。
- **未完了**：現在の稼働GASからの全ファイル実取得、稼働デプロイID/バージョンの確認、第三者が復元できる安全なバックアップの確認、既存doPost/19関数の現物照合、実Sheet監査項目、実管理者認証、実iPhone検証。Issue #66は未完了、管理書き込みはOFF。


## 2026-11-02 15時台：Apps Scriptの複数ファイルを漏れなく照合する改善（開発版のみ）

- GASの構造を検査する画面では `.gs` と `.txt` を選択する。HTMLServiceの `.html` や `appsscript.json` は関数の構造解析には含めず、**別のバックアップ照合画面**でファイル名とSHA-256内容を比較する。
- バックアップ照合は `.gs/.txt/.html/.json` に対応。各30ファイル・合計8MBまで、順不同の一致/不一致を検査する。同じファイル名が重複（大文字小文字違い、Unicode正規化後の同名も含む）した集合は、元のディレクトリ構造を推定できないため無条件に拒否。
- 関数検査・バックアップ比較の双方はブラウザ内のみ、ソース本文/ファイル名/秘密情報/ハッシュのネットワーク送信、サーバー保存、診断JSONへの混入はしない。
- バックアップの内容一致は**ユーザーが選択した2組だけ**を証明する。全ファイルを選択したこと、実稼働GASのデプロイ版と同じこと、バックアップが別の保管先から復旧可能なことの証明にはならない。
- 実Chrome 390pxで、`Code.gs` / `Index.html` / `appsscript.json` の順序違いで一致、ファイル不足/manifest内容変更で不一致、完全重複名/大文字小文字違いの重複名で拒否する検査を追加。さらに両側の非同期ファイル読取が終わる前に結果消去し、遅延応答しても古い照合結果が復活しないことを確認するテストを追加。
- 本番の稼働Apps Scriptソースと公開デプロイ版はまだ取得・照合していない。Issue #66の完了とはしない。管理書き込みOFF・Draft PR #76維持。


## 2026-11-02 16時台：選択変更の失効処理とGAS付与履歴の厳密な再送照合

- モバイル端末内GASソース検査で別のファイルを選択した瞬間に、前の検査件数・分類・診断JSONダウンロードを無効化する。バックアップ比較でも比較元か比較先のどちらかを選び直した時点で前の「一致」を消し「未照合」と表示。旧ファイルの非同期読取/SHA-256が遅れて完了しても、**新しい選択を過去の結果で上書きしない**。実Chromeでは通常の選択変更と、処理中の選択変更の両方を検証。
- **保存済みGAS候補（未稼働）** `GAS_WebAdminOps_20261030.gs` と `GAS_Code_FULL_WEB_OPS_20261030.gs` の `mioAdminOpsGrant_` を安全修正：操作ID再送時、操作種別・MIO-IDに加え、**付与前の回数、付与数、付与後の回数、付与理由、対象者名**がすべて監査履歴と一致しなければ拒否する。付与前+付与数の合計値だけが一致する別操作は拒否。
- 同じく `mioAdminOpsRecordGrant_` で、既存の付与履歴の操作ID/対象ID/回数/前後残数だけでなく、**付与理由と対象者名**の一致を必須化。通信断後の「処理中」復旧でも不整合を確定させない。
- 外部へ配布・デプロイしない `private-docs/MIO_Code_FULL_COPY_WEB_ADMIN_20261030.html` の埋め込みソースも、統合候補とバイト完全一致するよう同じ修正を反映。テスト `mio-private-full-copy.test.mjs` はコピー用HTMLが旧コードにずれた場合に不合格となる。
- `tests/mio-web-admin-ops.test.mjs` に、同操作ID・同合計でも内訳違い、理由変更、監査名前改変、処理中の付与履歴理由/氏名の改変を**追加付与なしで拒否**する回帰を追加。さらに単独・統合GAS候補の管理系19関数のソース一致も強制。
- **重要**：これらはGitHub内の保存済み候補の修正であり、**実稼働GASの現行ソース・デプロイ版を取得、書き換え、更新、配備したものではない**。本番のガチャ券数、景品、当選履歴、MIO-ID、皆勤、FAに変更なし。Issue #66の安全な現物照合・承認ゲートは引き続き閉じたまま。
