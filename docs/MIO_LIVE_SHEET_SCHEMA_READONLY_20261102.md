## 調査範囲と保護
既存管理スプレッドシートを、接続済みGoogle Drive/Sheetsの**読み取り専用API**で確認。初回の構造確認はタブ名と最上行の列見出しだけ。初回調査では参加者名・Web参加ID実値・認証ハッシュ・Cookie・管理者コード・ガチャ残数・当選履歴の**データ行は読み取っていない**。後述の追加照合では、**登録状況だけを集計するため必要最小限の状態列と行存在判定列**を読み取り、個人名・ID・トークンを出力していない。Googleシートの変更・新規タブ作成・式/セル更新・GASデプロイは一切行っていない。

同時に、保存済みGitHub `GAS_WebAdminOps_20261030.gs` と `GAS_Code_FULL_WEB_OPS_20261030.gs` の**予定されている列操作**を照合。**これは本番稼働中のGASがこのコードと同一である証拠ではない。**

## 管理センターの書き込み解放をSTOPする理由

1. **専用の監査タブが存在しない**。旧候補は最初の管理操作で自動作成していたが、現行Draft候補では欠落時に処理を停止する。許可なしの本番スキーマ変更はしない。
2. **既存の付与履歴J列は空見出し**。現行Draft候補は`Web操作ID`を自動で追加せず、列が未整備なら付与そのものを拒否する。将来の列追加にはバックアップと運営承認が必要。
3. 管理台帳の構造を確認できても、**稼働中Apps Scriptのソース・デプロイ版・同名19関数の重複**はまだ確認できていない。Drive上から該当Apps Scriptプロジェクトを直接取得できていない。
4. `mioAdminOpsRead_`については候補コードを静的照合した限り、Sheetの`setValue`/`insertSheet`等の処理は含まれない。ただし、**実際に本番接続してreadが正常終了するかは未確認**。本番GASコードの確認までは操作しない。
5. 既存サイト`https://emuzii-mio-1st-web-v12.vercel.app/`、MIO-ID、ログインID、端末認証、回数・抽選権・皆勤、景品画像、過去当選履歴をすべて保護する。
