# 【廃止・実行禁止】旧 GAS 全文貼り替え手順（2026-11-02）

このファイルは、過去のテストと案内で参照されたファイル名を維持するためだけの**移行案内**です。旧「Code.gsを全選択して統合版全文を貼り付ける」方法は、現在の稼働GASソース・デプロイ版・同名関数を未照合のため**実施しないでください**。

**現在有効な手順：** [既存GASを壊さない接続・バックアップ・差分確認・停止条件](MIO_GAS_SAFE_EXISTING_DEPLOYMENT_20261102.md)

- 既存の Apps Script **同一プロジェクト・同一デプロイ・同一URL** を保つ。新規GASプロジェクト/新しいデプロイURLは作らない。
- まず現在稼働中の `Code.gs` と別ファイル・`doPost`・トリガー・プロジェクトのデプロイ版を照合し、**変更前にバックアップ**する。
- 保存済み統合候補とは19件の同名関数衝突の可能性がある。無確認の全文置換、別モジュールの無確認追加、既存の`doPost`置換をしない。
- 重複がないと確認した**限定差分だけ**、必要な承認を得て適用候補とする。read-only接続で既存のMIO-ID/登録/Cookie/ガチャ回数/皆勤/FA/当選履歴の維持を確認する。
- `MIO_GACHA_ADMIN_OPS_RELEASE` の書き込み機能はOFFのまま。GAS実機照合・バックアップ・権限・回帰検査・運営承認まで開放しない。
- `setup()` / 初期化や既存参加者/当選/皆勤の台帳変更は、この作業では一切しない。

過去に使われていた `GAS_Code_FULL_WEB_OPS_20261030.gs` は、**本番に貼り付ける対象ではなく、差分照合用の保存済み候補**としてのみ保管します。
