# みおシステム vNext — ファンアート応募・審査・掲載（リリース条件）

更新日: 2026-10-28
状態: 開発ブランチの実装のみ。既存本番には反映しない。

## 既存機能の実態
- 公開: `gallery.html` → `/api/gallery/items`。管理者による既存作品の編集・非公開・復元は `gallery-manage.html` → `/api/gallery/moderate`。
- 新規応募: 既存の公開画面は「受付は後日開始」、旧 `/api/gallery/publish` は503停止。新規応募の実働経路はこれまでなかった。
- 旧 `gallery-items.js` の既存作品リストを正本として維持し、既存掲載経路には基本的に触れない。

## vNextで新たに追加した機能
1. `gallery-submission-ui.js`: 新規受付が許可された場合だけ、`gallery.html` 内に応募フォームを表示。作品タイトル、掲載名、種類、HTTPS作品URL、説明、掲載権利と公開同意を送る。ファイル直接アップロードは今回対象外。
2. `gallery-submissions-core.js`: URL、文字列長、種類、必須同意などの入力検査。認可された状態遷移を定義。
3. `api-gallery-submissions.js`: 公開GETで受付可否を返し、POSTの応募をデータベースに保存。作品はすべて審査待ち。HTTPS限定、同一URL重複抑止、連続応募制限（接続情報のHMAC識別値）、管理者審査時の承認済み端末・セッション検証、改訂番号による同時更新競合防止、監査ログ記録。
4. `gallery-submissions-admin.html`: 認証済み運営端末で応募一覧を確認、承認・不採用・非公開・再公開・再審査。既存管理メニューから接続。
5. `api-gallery-items.js`: 明示的な公開許可フラグが有効な場合のみ、承認済み応募を既存作品とともに公開。未承認・不採用・非公開は結果に含めない。
6. `db/gallery-submissions.sql`: 新規専用テーブルと重複防止インデックス。リクエスト実行時にスキーマは作らない。
7. `tests/gallery-submissions.test.mjs`: 入力検証、HTTPS制限、状態遷移、デフォルト受付停止を確認。

## 機能の限界
- 応募者はログインしなくても公開作品URLを提出できる。自動公開しない。作品画像ファイル自体のアップロードは未対応。
- 応募内容は承認後にタイトル、掲載名、説明、カテゴリ、作品URLが公開される。識別値、審査状態、内部IDは公開一覧に含めない。
- プレビューURLの管理者操作は、既存管理APIの本番ホスト制限によって未検証。本番の認証済み端末で確認する必要がある。
- `source_hash` は接続元IP等のハッシュ化識別子で、元のIPをそのまま保存しない。保持期間と削除手続きはリリース前に確定する。
- 本番・ガチャ・既存参加者ログイン・皆勤賞のデータと既存の認証設定は今回の開発コミットで変更しない。
