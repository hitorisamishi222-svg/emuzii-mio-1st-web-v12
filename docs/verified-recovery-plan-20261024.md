# 本人確認済み端末復旧（開発版・未公開）

## 実装済み（このブランチのみ）
- `recovery-identity.js`: 15分以内の再試行鍵から、同じWeb-IDとトークンを決定的に導出。Cookie喪失そのものの復旧ではない。
- `recovery-result-gate.js`: GASの明示的な本人確認承認、ワンタイム消費、既存Web-IDとMIO-IDの完全一致を必須にする。

## 本番接続前の必須条件
1. 稼働中のGAS全ソースとデプロイ版を読み取り専用で取得し、認証・承認・更新列を照合する。
2. 管理者が本人確認を済ませた対象の既存Web-ID/MIO-IDを指定し、期限付きワンタイム復旧許可を発行する。**ログインID・名前・IPだけで本人確認しない。**
3. GAS側でトークンハッシュを既存行と照合・更新する方式を決定し、同時実行ロック、原子的一回限り消費、監査ログ、旧セッションの失効方針を実装・検証する。本人確認が不明なら拒否する。
4. 対象の既存Web-ID、MIO-ID、皆勤・FA・ガチャ・予想の履歴を保存し、新しい参加者行を作らない。
5. 本番から分離したテストデータで拒否・期限切れ・二重消費・並列実行・通信切断後再送を検証する。
6. Vercel側の公開APIは現時点では**作成も有効化もしない**。既存の登録制限とブラウザペアリングの無効化を維持する。

## 現状
上記2つのヘルパーだけではログインは復旧しない。GAS本番の読取権限がないため本番反映を停止中。第二保存データに触れない。
