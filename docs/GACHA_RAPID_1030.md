3. 管理者のGoogleアカウントで `gachaRapidInstallMenu()` を一度だけ実行し、必要なGoogle承認を確認。
4. シートを再読み込みし、パソコン版の「🐳 緊急ガチャ管理」から一括管理画面を開く。

7. 本人の端末のガチャ画面で、登録済み認証と管理者承認結果を照合する。ガチャOFFは保持。

**注意**：2ファイル版（`GAS_GachaRapid_20261029.gs` + `GachaRapidUI.html`）は互換版。**1ファイル版と2ファイル版を両方追加しない**。同じ関数が重複する。Google Sheetsのスマホアプリでカスタム管理ダイアログを直接利用できるとは限らないため、スマホ時は下記の管理タブを使用する。

注意：iPhone/AndroidのGoogle SheetsアプリではApps Scriptカスタムメニューを使用できないことがある。モバイルで当面利用する場合は、緊急管理シートと元台帳を使う。スマホ用ワンタップ承認APIの公開には、追加開発・認証テストが必要。

## ガチャだけ来た人の流れ
1. 本番配信されたガチャ専用登録ページから、本人の端末・ブラウザで登録。
2. Web登録の承認待ち申請を管理者が確認。
3. 購入証拠・本人確認・MIO-IDの重複有無を確認。
4. 既存の参加者IDがある場合はそのIDを使う。なければ空きの正規参加者行に新規登録。
5. Web登録のF承認/Gメンシプ確認/H ID/K統合ID/L本人確認/M確認日時とガチャC/D累計口数を検証。
6. 「総権利・残回数・入力チェックOK」を確認し、後日ガチャ受付がONになれば本人が抽選できる。

## 制約
- 本番GASが旧バージョンの場合、既存名の新端末申請がログインID照合で停止する場合がある。ユーリさん等には再登録を繰り返させない。
- 専用登録と簡易登録（Neon）は異なる。簡易登録だけではGASガチャの認証は成立しない。
- ガチャ公開ONはこの作業に含めない。
- 既存のMIO-ID、皆勤、当選履歴、ガチャ権利を保持し、二重付与・名前だけの本人認証を禁止。
- Apps Scriptの元プロジェクトは本GitHub変更では更新されない。ワンクリック承認機能の本番導入・実機試験は残作業。

## 10/30 台帳の数式保護修正（開発ブランチ）
- 実シートの `emuzii_Web登録` では K「統合参加者ID」・L「みお確認」が一部の行で数式、一部の行で手入力になっている。数式があるセルは **書き換えずに**承認後の計算結果を照合し、数式のない行だけ従来の確認値を入力する。
- Q「運営端末指定」は端末状態ではないため、承認時に「使用中」と上書きしない。N「端末状態」は既存の計算式を尊重する。
- 本修正は開発PR内のみ。実GASには未適用。既存の承認済み参加者への再登録は避ける。
