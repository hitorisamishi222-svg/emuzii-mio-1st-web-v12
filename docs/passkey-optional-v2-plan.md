# みおシステム v2 パスキー任意導入仕様（開発版）

状態: 設計確定 / 実装未着手。本番反映禁止。

## 運用
- 既存MIO-IDと皆勤・ガチャ残回数・当選・FA履歴を維持。パスキー登録は任意。
- 既存ログインは維持し、パスキー登録を強制しない。
- お知らせ掲載は、サーバー認証・復旧・機種変更テスト完了後。
- パスキー登録導線はマイページ→セキュリティ設定。本人確認済みのセッションでのみ開始。
- 既存MIO-IDを知るだけではパスキーを登録・紐付けできない。
- 別端末の利用は既存の端末切替承認方針を尊重。同期パスキーは端末固定の証明にならない。

## WebAuthn サーバー必須
1. RP ID・originを厳格に固定。公開ドメインとプレビュードメインの資格情報は混在させない。
2. 登録チャレンジを短寿命・単回使用で発行。ログイン中のMIO-IDに紐付け、ユーザー確認(uv)を要求。
3. 認証チャレンジを短寿命・単回使用で発行。署名、challenge、origin、RP ID hash、user verificationを検証。
4. credential ID、公開鍵、signCount、MIO-ID、登録日時、失効状態のみ最小保存。秘密鍵・生体情報は保存しない。
5. セッションはSecure/HttpOnly/SameSite Cookieでサーバー管理。CSRF・レート制限・監査ログ・セッション失効を実装。
6. パスキー紛失時は別の登録済み認証手段か管理者本人確認による復旧。メール/電話番号を必須にしない。
7. パスキー削除・追加・端末切替は直前の再認証を要求。権限のないMIO-IDへの紐付けを禁止。
8. 本番の登録者・ガチャ残回数・皆勤データへの書き込みは、検証完了まで一切行わない。

## テスト
- 既存会員のログイン継続、任意登録、登録拒否時の従来ログイン継続
- パスキー認証成功/失敗/キャンセル、ブラウザ差異、同期パスキー、新端末
- 期限切れ/再使用challenge、別origin、別MIO-ID、権限昇格、紛失・復旧
- お知らせからマイページへの導線、スマホSafari/Chromeでの表示
