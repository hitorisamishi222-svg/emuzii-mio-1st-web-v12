3. 保存済み候補`GAS_WebAdminOps_20261030.gs`と`GAS_Code_FULL_WEB_OPS_20261030.gs`の**同名19関数の重複リスク**を照合。既存`doPost`を全文置き換えない、同名関数を重複定義しない、既存イベント認証を別ルートで上書きしない。
4. 既存コードに必要な操作があれば、**追加不要**としてread-only接続互換を優先。ないと判明した関数だけ、既存同一プロジェクトの限定差分として別途レビューする。書き込みを伴う作業は明示承認なしに実施しない。
5. 安全差分の承認と復元用バックアップがある場合だけ、**既存デプロイの管理画面から新バージョンを更新**。新規GASプロジェクト・Webアプリ・URLの発行は禁止。
6. 最初は`action:'read'`だけ確認し、本人確認情報・MIO-ID・ガチャ回数・皆勤・当選履歴の前後同一性を確認。書き込み環境フラグ`MIO_GACHA_ADMIN_OPS_RELEASE`はOFFのまま。実機検証後の最終公開は別途運営承認を要する。
